# Ralph Compute — Multi-page Website

Static, responsive website. Open `index.html` or deploy the folder to GitHub Pages, Netlify, or Vercel.

Pages: Overview, Platform, Developers, Architecture, Roadmap, FAQ.

## Setup
- Official X link is set to https://x.com/RalphComputeXyz.
- Contract address is deliberately **not announced**. When official CA is confirmed, edit the `.contract-field` block in all six HTML pages and enable the copy button with appropriate JavaScript. Do not publish an unverified CA.
- The hero uses `assets/background-web.png`, the supplied image, with a dark overlay for subtle contrast.
- Product descriptions are clearly marked planned/concept. No API backend is included; example requests are not live.
- No build dependencies; all pages link to shared `style.css` and `script.js`.
